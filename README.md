# 拷贝漫画绿色版

基于拷贝漫画 Android **3.0.9（83）** 制作的 ARM64 精简安装包，当前版本为 **3.0.9-r2**。

[下载安装包](https://github.com/ygstgddr/CopyManga-Green/releases/latest) · [发布说明](RELEASE.md)

## 精简内容

- 移除广告 SDK、广告初始化、附带原生库和广告资源。
- 隐藏首页营销轮播、首页公告/赞助弹窗。
- 隐藏会员购买入口、奖励广告和捐赠入口。
- 安装包从 **108.6 MiB** 缩小到约 **33.5 MiB**，减少约 **69%**。

会员授权、下载登录和积分要求保持原应用逻辑。本项目不代表原应用官方，仅发布修改后的安装包，不提供原应用源码。原应用、名称及相关内容的权利归其权利人所有。

## 安装

适用于 **Android 7.0 及以上的 ARM64 手机**。在右侧 Releases 下载以 `.apk` 结尾的文件，不要下载 GitHub 自动生成的 Source code 压缩包。

本包重新签名，可覆盖同签名的上一版绿色包；不能直接覆盖官方签名版本。若已有官方原版，先备份或同步书架、阅读记录和下载内容，再卸载原版安装，避免丢失本地数据。

## 验证与限制

已在 **vivo V2520A / Android 17 / ARM64** 实测两次冷启动、权限结果回调、首页推荐、搜索、漫画详情与章节、图片阅读及滚动翻页。r2 修复了上一版首次申请权限时白屏闪退的问题。

账号登录、离线下载与支付流程尚未验证。内置外链网页存在兼容性问题，可能无法打开。首页公告槽位已隐藏，普通公告也不会在该位置显示。测试通过不代表全部设备和全部功能均已验证。
